Code cleanups and fixes I've got to get around to sometime:

      and support reinitialization for the keyboard at runtime.

    - Make task set dynamic; should be able to mark a function
      as a task and assign it a bit in the pending work bitmap.
      (this will be useful in the future for stuff like dynamically
      loading drivers based on discovered devices too)

      by adding timeouts and making the it execute with IRQ 0
